# TARGET PROJECT (EMA/2020/46/TDA/19)
👋 Welcome to the GitHub organsation of the [TARGET-EU project: Comparative effectiveness and safety studies using the target trial emulation and estimand frameworks](https://catalogues.ema.europa.eu/node/4440/administrative-details). Here you'll find repositories containing code that implements each TARGET-EU case study, along with documentation of that code and dummy data which allows users to run and understand the code.
