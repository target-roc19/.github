# TARGET PROJECT (EMA/2020/46/TDA/19)
👋 Welcome to the GitHub organsation of the [TARGET-EU project: Comparative effectiveness and safety studies using the target trial emulation and estimand frameworks](https://catalogues.ema.europa.eu/node/4440/administrative-details). On the [EMA catalogue](https://catalogues.ema.europa.eu/node/4440/administrative-details) you can find information about the TARGET-EU project as a whole, as well as links to each individual case study.

On this github page you'll find repositories containing code that implements each TARGET-EU case study, along with documentation of that code and dummy data which allows users to run and understand the code. 

## Overview

Each TARGET-EU case study (CS) has its own analytical pipeline, stored in a public github repository, containing both the code, codebooks and metadata associated with the study, listed and linked below. Each repository contains dummy/test data, with dummy CDM input data available on request where not shared currently in the repository itself.

- [CS01. EMA Catalogue Entry [here](https://catalogues.ema.europa.eu/node/4899/administrative-details).
